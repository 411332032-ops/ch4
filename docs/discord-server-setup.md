# Discord Server 設定步驟

> 目標：建立你自己的 Discord Server、建一個給 agent 用的頻道、拿到 `CHANNEL_ID`、產生邀請連結讓同組同學加入。
> 適用：**Windows**（用 Discord 桌面版或瀏覽器版都可以，畫面幾乎一樣）。
> 提醒：Discord 偶爾會調整畫面，如果你看到的按鈕名稱和這裡稍有不同，找意思最接近的那個。每個名稱我都附上了中文與英文（Discord 依你的語言設定顯示其中一種）。

名詞先說明：

- **Server（伺服器）**：Discord 裡一個獨立的聊天空間，像一棟大樓。
- **頻道（Channel）**：Server 裡的一個房間。agent 只會在你指定的那一個房間工作。
- **CHANNEL_ID**：Discord 給每個頻道的一組數字編號。程式靠它知道「要聽哪個房間」。

---

## 事前準備

1. 開啟 Discord（桌面版，或用瀏覽器開 `https://discord.com/app`）。
2. 確認你已登入自己的帳號。

---

## 一、建立你自己的 Discord Server

1. 看畫面**最左邊**那一條直的圖示欄。往下找，有一個圓形的 **`+`** 按鈕（提示文字是「新增伺服器」／Add a Server）。**點它。**
2. 跳出視窗，點最上面的 **「自己建立」／Create My Own**。
3. 下一個畫面問你這個 Server 是給誰用的，點 **「僅供我和我的朋友使用」／For me and my friends**。
4. 在「伺服器名稱」／Server Name 欄位，輸入你想要的名稱，例如 `食物記錄測試`。
5. 點右下角的 **「建立」／Create**。

✅ **你應該看到**：最左邊圖示欄多了一個你的 Server 圖示，畫面中間出現你的 Server，左邊有預設的頻道（例如 `一般` ／ `general`）。

---

## 二、建立給 agent 用的頻道

1. 看畫面**左邊第二欄**（Server 名稱下面的頻道清單）。找到「文字頻道」／**Text Channels** 這個分類標題。
2. 把滑鼠移到「文字頻道」那一行，右邊會出現一個 **`+`**（提示文字：「建立頻道」／Create Channel）。**點它。**
3. 「頻道類型」／Channel Type 選 **「文字」／Text**。
4. 「頻道名稱」／Channel Name 輸入：`food-log`（建議用英文小寫，之後比較好認。Discord 會自動把空格改成 `-`）。
5. **不要**勾選「私人頻道」／Private Channel（這次要讓同學進得來）。
6. 點右下角的 **「建立頻道」／Create Channel**。

✅ **你應該看到**：左邊頻道清單多了 `# food-log`，點進去是一個空的聊天室。

---

## 三、拿到 CHANNEL_ID

Discord 預設不顯示編號，要先打開「開發者模式」。

### 3-1. 打開開發者模式

1. 看畫面**左下角**你的頭像旁邊，有一個**齒輪圖示**（提示文字：「使用者設定」／User Settings）。**點它。**
2. 在左邊選單往下找，點 **「進階」／Advanced**（在「App 設定」／App Settings 區塊底下）。
3. 找到 **「開發者模式」／Developer Mode**，把右邊的開關**打開**（開關變成綠色）。
4. 按右上角的 **`ESC`**（或 **X** 按鈕）離開設定。

### 3-2. 複製頻道編號

1. 在左邊頻道清單，對著 `# food-log` **按滑鼠右鍵**。
2. 在跳出的選單最下面，點 **「複製頻道 ID」／Copy Channel ID**。

✅ **你應該看到**：沒有任何提示（複製成功是靜悄悄的）。編號已經在你的剪貼簿裡。

### 3-3. 把它存起來

1. 打開**記事本**（Notepad）。按 `Win` 鍵，輸入「記事本」，按 Enter。
2. 按 `Ctrl + V` 貼上。你會看到一串 **17 到 20 位的數字**，例如 `123456789012345678`。
3. 先放著不要關，之後設定 `.env` 時要用到（見 `discord-bot-setup.md` 最後一節）。

> 📌 `CHANNEL_ID` 不是密碼，外洩不會讓別人控制你的 bot。但沒必要公開貼出去。

---

## 四、產生邀請連結，讓同組同學加入

### 4-1. 建立連結

1. 對著 `# food-log` 頻道，把滑鼠移上去，右邊會出現一個**小人加號**的圖示（提示文字：「建立邀請」／Create Invite）。**點它。**
   - 找不到的話：點畫面左上角你的 **Server 名稱**（有向下箭頭），選 **「邀請朋友」／Invite People**。
2. 跳出視窗，最下面有一條邀請連結。**先不要複製**，點視窗最下方的 **「編輯邀請連結」／Edit invite link**（或右下角的小齒輪）。
3. 設定如下：
   - **「連結到期時間」／Expire After**：選 **7 天**／7 days
   - **「使用次數上限」／Max Number of Uses**：選一個比組員人數略多的數字，例如 **10 次**／10 uses
   - **「授予臨時成員資格」／Grant temporary membership**：**不要勾**
4. 點 **「產生新連結」／Generate a New Link**。
5. 點旁邊的 **「複製」／Copy**。

### 4-2. 傳給同學

把複製的連結（長得像 `https://discord.gg/xxxxxxx`）貼到你和同學的群組（LINE、Messenger 等）。同學點連結、按「接受邀請」／Accept Invite 就會加入。

### 4-3. 為什麼要設到期和次數

- 任何拿到連結的人都能進來，而**進入 `food-log` 頻道的人都能消耗你的 Claude 額度**（每傳一張照片就用一次）。
- 設到期和次數上限，可以避免連結被轉傳出去，讓不認識的人進來。
- 測試結束後，請把邀請連結作廢：**Server 名稱 → 伺服器設定／Server Settings → 邀請／Invites → 在該連結右邊按 X 刪除**。
